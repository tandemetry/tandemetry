# Audit 2026-11-13

Scope: whole repository after the unified event model (#18). Load assumed: one organisation,
a few hundred repositories, backfill bursts of millions of events.

**What the repo does:** a skeleton with the unified event model (deterministic `event_id`), a
validated agent signatures catalog, a `--version` CLI, a Docker Compose stack (Kafka, ClickHouse,
PostgreSQL) and CI. No ingest, Kafka code, ClickHouse tables or metrics yet.

No bugs found in `src/`: no code comments, one-line docstrings, mypy strict, behaviour tests.
